# SECTION 2: THE THESIS

## Why Blackout Periods Should Matter

Apple Inc. operates the largest stock buyback program in corporate history:

| Metric | Value |
|--------|-------|
| FY2025 Total Buybacks | $90.7 billion |
| Quarterly Pace | $20-25 billion |
| Cumulative Since 2012 | $650+ billion |
| % of All S&P 500 Buybacks | >10% |
| Average Daily Volume | ~42 million shares |
| Max Daily Buyback (Rule 10b-18) | ~10.5M shares (~$2.7B) |

**The Logic:** When this massive buyer (~$20-25B/quarter) steps away during blackout periods, supply/demand dynamics should shift negatively.

## Blackout Period Definition

| Parameter | Value | Description |
|-----------|-------|-------------|
| Start | T-35 days | 5 weeks before earnings announcement |
| End | T+2 days | 2 trading days after earnings |
| Total Duration | ~37 days | Approximately 25 trading days |

# SECTION 9: METHODOLOGY

## Data Sources

| Data Type | Source | Update Frequency |
|-----------|--------|------------------|
| AAPL Price Data | Yahoo Finance (yfinance) | Daily |
| SPY Price Data | Yahoo Finance (yfinance) | Daily |
| Earnings Dates | Wall Street Horizon, SEC filings | Quarterly |
| Buyback Data | SEC 10-Q/10-K filings | Quarterly |

## Calculations

### Excess Return
```
Excess Return = AAPL Total Return - SPY Total Return
             = (AAPL_end / AAPL_start - 1) - (SPY_end / SPY_start - 1)
```

### Win Rate
```
Win Rate = (Periods with Excess Return > 0) / Total Periods × 100
```

### Statistical Significance
```
T-test: Two-tailed, testing if mean excess return ≠ 0
Significant: p-value < 0.05
Marginally Significant: p-value < 0.10
```

## Limitations

1. **Sample Size:** 14 January cycles is limited for statistical confidence
2. **Regime Analysis:** Only 4-9 cycles per regime category
3. **10b5-1 Plans:** ~60% of buybacks may continue via pre-programmed trades
4. **Confounding Factors:** Earnings surprises, guidance, macro events
5. **Historical Patterns:** May not persist in future market conditions
